# Weather Forecast Application

A lightweight Vanilla JavaScript weather dashboard that fetches real-time meteorological data for any city using the public `wttr.in` JSON API.

## Features

- Search current weather conditions by city name (via button click or pressing `Enter`).
- Displays temperature, "feels like" temperature, weather condition icon, humidity, wind speed, cloud cover, and visibility.
- Graceful loading and error states when a city name is empty or cannot be found.

## Usage

Open `index.html` directly in your browser or serve the folder using VS Code Live Server.

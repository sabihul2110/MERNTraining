# E-Commerce Storefront (React + Redux Toolkit)

A single-page e-commerce storefront built with React 19, Redux Toolkit, React Router, Axios, and Tailwind CSS (powered by Vite).

## Key Features

- **Dynamic Product Catalog**: Fetches product listings from the DummyJSON Products API with configurable result limits.
- **Multi-Field Search**: Filters products across title, category, brand, and tags.
- **Global Cart State (Redux Toolkit)**: Supports adding items, incrementing/decrementing item quantities, removing items, and calculating item subtotals and order grand totals.
- **Client-Side Routing**: Navigates between the catalog home view (`/`) and the shopping cart summary (`/addToCart`).

## Getting Started

```bash
npm install
npm run dev
```
